## 게임 구조 개요

```
기본 게임 (1)                      확장 시스템 (2)
─────────────────────              ─────────────────────────────
하루 1명 손님                  →   100일 플레이 데이터 수집
최고의 버거 1개 제작                 ↓
3~10분 소요                         AI가 플레이 패턴 학습
신선도 + 굽기 + 시간 = 점수          ↓
100일 리그 & 랭킹                    AI 셰프(백기준) 경쟁 시스템
```

## 기본 게임 — 오늘의 버거

### 컨셉

매일 단 한 명의 손님을 위해, 단 하나의 최고 버거를 만드는 파인다이닝 게임입니다.
빠른 패스트푸드가 아니라 **정성과 정확도**가 핵심입니다.

- 1일 1게임, 1손님, 1버거
- 플레이 타임: 3분(숙련) ~ 10분(신중)
- 매일 같은 시드로 생성된 손님 → 전 플레이어 동일 조건

### 평가 3요소

| 요소 | 설명 | 측정 방식 |
|---|---|---|
| 신선도 | 재료를 얼마나 적시에 수확/사용했는가 | 수확~사용 경과 시간 |
| 굽기 | 손님이 요청한 굽기를 얼마나 정확하게 맞췄는가 | 15단계 게이지 판정 |
| 시간 | 총 소요 시간 (빠를수록 보너스, 단 정확도 우선) | 완성까지 경과 초 |

### 최종 점수 계산

```
일일 점수 = (신선도 점수 × 0.35) + (굽기 정확도 × 0.45) + (시간 보너스 × 0.20)

굽기 판정:
  Perfect (중간 칸)   → ×1.5
  Good    (양쪽 칸)   → ×1.0
  Failed  (범위 외)   → ×0.0

시간 보너스:
  3분 이내   → +20%
  5분 이내   → +10%
  10분 초과  → 없음
```

### 100일 리그 시스템

```
시즌 구조:
Day 1 ~ Day 100  →  매일 점수 누적
                 →  주간 랭킹 업데이트 (7일 단위)
                 →  시즌 최종 랭킹 확정

리그 티어 (점수 기준):
  🥇 마스터 셰프   상위 5%
  🥈 수석 셰프     상위 20%
  🥉 주방장        상위 50%
  🍳 견습 요리사   그 외
```

## 확장 시스템 — AI 경쟁 모드

100일 시즌 종료 후, 수집된 플레이 데이터를 기반으로 AI 셰프(백기준)를 학습시켜 경쟁 시스템을 구축합니다.

### 데이터 수집 구조 (100일 시즌 중)

100일 동안 플레이어가 만들어내는 모든 행동이 학습 데이터가 됩니다.

```
수집 데이터:
- 스테이션별 체류 시간
- 재료 수확 타이밍
- 굽기 게이지 멈춤 위치
- 조립 순서 및 소요 시간
- 최종 점수 및 판정 결과
```

### AI 학습 설계 (Phase 2)

**WebGL 호환 방식**: 수집 데이터로 Python 학습 → ONNX Export → Unity Inference Engine 실행

**상태(State) — 관찰값:**
- 현재 굽기 게이지 위치 (0.0 ~ 1.0 정규화)
- 재료 신선도 잔량 (0.0 ~ 1.0)
- 보유 재료 수량 (빵/패티/베이컨/소스, 각 0~5)
- 경과 시간 (0.0 ~ 1.0 정규화)

**행동(Action) — 이산:**
- 0: 굽기 멈추기 (타이밍 결정)
- 1: 다음 스테이션으로 이동
- 2: 재료 수확/수거
- 3: 발주대로 이동 (재료 보충)

**보상(Reward):**

| 조건 | 보상 |
|---|---|
| Perfect 굽기 | +1.0 |
| Good 굽기 | +0.5 |
| 높은 신선도 서빙 | +0.3 |
| 재료 소각 | -0.5 |
| 신선도 0 서빙 | -0.3 |

### AI 셰프 난이도

100일 데이터로 학습된 AI는 플레이어의 평균 실력을 기준으로 난이도가 자동 조정됩니다.

| 난이도 | AI 특성 |
|---|---|
| 입문 | 룰 기반, 상위 75% 수준 모방 |
| 일반 | 100일 데이터 기반, 상위 50% 수준 |
| 고수 | 상위 20% 플레이 패턴 학습 |
| 마스터 | 상위 5% (마스터 셰프) 플레이 패턴 재현 |

## 기술 스택 및 아키텍처

### 핵심 스크립트 구조

```
Assets/Scripts/
├── Core/
│   ├── GameMode.cs          ← enum: Daily | VsAI
│   ├── OrderManager.cs      ← DailySeed 기반 손님/주문 생성
│   ├── ScoreManager.cs      ← 신선도·굽기·시간 복합 점수 계산
│   └── SeasonManager.cs     ← 100일 리그 진행·랭킹 관리
├── Game/
│   ├── GrillGauge.cs        ← 15단계 굽기 게이지
│   ├── FreshnessTracker.cs  ← 재료별 신선도 시간 추적
│   └── AIChef.cs            ← 백기준 행동 제어 (룰기반 → ONNX)
├── Data/
│   └── PlayDataRecorder.cs  ← 100일 플레이 데이터 수집 (AI 학습용)
└── UI/
    ├── DailyResultHUD.cs    ← 일일 점수 결과 화면
    ├── LeaderboardHUD.cs    ← 랭킹/리그 화면
    └── VsHUD.cs             ← AI 대전 비교 HUD
```

### 플랫폼

- **Unity 6.3 LTS**, WebGL (모바일 최적화)
- **데이터 수집**: Firebase Realtime DB (100일 플레이 로그)
- **ML-Agents**: Python 학습 환경 → ONNX Export → Unity Inference Engine

## B2B 전략

이 프로젝트는 게임 외적으로 B2B 파트너십을 통한 수익화 모델을 준비하고 있습니다.

- 통신사 가족 요금제 부가서비스 연계
- 시니어 케어 플랫폼 협력
- 요식업 교육/훈련 플랫폼 확장
